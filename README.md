# Planeación del Proyecto de Software
Este repositorio documenta la planeación y seguimiento del proyecto desarrollado en el programa **Análisis y Desarrollo de Software (ADSO)** del SENA.

**Fases del proyecto:**
1. Análisis de requerimientos.
2. Diseño del sistema.
3. Desarrollo frontend.
4. Desarrollo backend.
5. Pruebas y ajustes finales.
